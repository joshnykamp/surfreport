# 07 Wearable session data (future idea)

**Status:** Idea

## Goal
Use surf sessions recorded on watches (Apple Watch, Garmin) as an objective signal of actual conditions, alongside human observations.

## Possible signals
- Session start, end and duration
- Waves caught, ride length and speed (from surf tracking apps)
- Movement patterns that suggest wave size or how busy the session was

## Why it matters
Harder to fake than a manual rating, so it helps with the trust problem in stage 06.

## Open questions
- Which platforms expose this data (HealthKit surfing workouts, Garmin Connect, surf tracking apps) and under what terms?
- How do users opt in, and what privacy rules apply to location data?
- Does movement data actually correlate with wave size and quality?
